# Security and launch gate

## Реализовано в пилоте

- серверная валидация полей;
- ограничение размера JSON-запроса;
- rate limit по IP и endpoint;
- `HttpOnly`, `SameSite=Lax` cookie;
- CSRF-токен для авторизованных запросов;
- хеширование паролей через `scrypt`;
- атомарная запись базы;
- дедупликация лида за 30 дней на партнёра;
- CSP, `nosniff`, `frame-ancestors`, `Referrer-Policy`;
- персональный доступ партнёра только к своим лидам.
- восстановление пароля с одноразовым токеном, сроком действия 15 минут и отзывом активных сессий;
- административный пароль хешируется один раз при запуске, а не заново при каждом входе;
- безопасный режим восстановления не раскрывает существование email.

## Не считать завершённым до публикации

1. HTTPS с действующим сертификатом.
2. PostgreSQL/Redis вместо JSON и in-memory sessions.
3. Bitrix24 webhook, подпись, повторная доставка и идемпотентность.
4. Политика ПДн, согласия, оферта и правила выплат.
5. CAPTCHA/anti-fraud, резервные копии, логи без утечки ПДн.
6. Настроить `PASSWORD_RESET_WEBHOOK_URL` и `PASSWORD_RESET_WEBHOOK_SECRET`, иначе endpoint восстановления только принимает запрос, но не доставляет письмо.
7. Установка реального `ADMIN_EMAIL` и сильного `ADMIN_PASSWORD` через secrets.
8. Проверка восстановления из backup и нагрузочный тест.
9. Пилот на ограниченной группе партнёров с измерением воронки.
