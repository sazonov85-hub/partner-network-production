# Partner Network - production-oriented pilot

Рабочий пилот партнёрской сети без внешних runtime-зависимостей:

- серверная регистрация партнёра;
- пароль с `scrypt`, сессии в HttpOnly cookie и CSRF-токен;
- JSON-хранилище с атомарной записью для пилота;
- персональный Partner ID и реферальная ссылка;
- передача заявки клиента с согласием и дедупликацией;
- кабинет партнёра со статусами заявок и балансом;
- health-check, rate limit, Content Security Policy;
- outbox-слой для последующего подключения Bitrix24;
- события и базовый административный обзор.
- публичная форма заявки по персональной ссылке без входа клиента;

## Запуск

```bash
ADMIN_EMAIL=admin@example.ru ADMIN_PASSWORD='change-this-password' node server.js
```

Открыть: `http://127.0.0.1:8787/`.

Переменные: `PORT`, `HOST`, `COOKIE_SECURE=1`, `BITRIX_WEBHOOK_URL`.

## Важно до публичного коммерческого запуска

JSON-хранилище подходит для пилота на одном сервере, но для масштабирования нужно заменить его на PostgreSQL, вынести сессии в Redis, включить HTTPS, настроить резервное копирование, мониторинг, реальные правила выплат, юридические документы и Bitrix24 webhook с подписью/idempotency.
